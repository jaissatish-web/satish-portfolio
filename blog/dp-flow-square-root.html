Why 25% differential pressure means 50% flow

Use a live curve to understand square-root extraction and avoid applying it twice.

By Satish Kumar Jaiswal · 2026-09-23

DP Flow Calculator

A differential-pressure flow installation often produces a DP proportional to the square of flow under its design assumptions. Consequently, the flow fraction is the square root of the DP fraction. A DP indicator and a flow indicator can therefore show different percentages while both are correctly configured.

Worked example

Maximum DP is 100 kPa and maximum flow is 200 m³/h. At 25 kPa, the DP fraction is 0.25. Its square root is 0.5, giving 100 m³/h. At 64 kPa, the flow is 160 m³/h.

Read the curve before changing a setting

The calculator plots flow against DP and marks the current input. Near zero DP, a small DP change represents a comparatively large change in the calculated flow fraction. Real installations may use a configured low-flow cutoff; this simple tool deliberately does not invent one.

Where does square-root extraction happen?

It may occur in the transmitter or the control system. Confirm the signal definition at both ends. If a transmitter already sends a signal linear in flow and the DCS applies another square root, the displayed result will be wrong. Document whether each signal represents DP or flow.

Know the model boundary

The calculation keeps fluid density and the primary-element coefficient fixed. It does not size an orifice plate or compensate gas flow for temperature, absolute pressure or compressibility. A change in process conditions can require a more complete calculation.

Try the tool

Keep maximum flow fixed and enter DP fractions of 0%, 25%, 50%, 75% and 100%. Notice that equal DP steps do not produce equal flow steps. Export the results for a calculation note, and use the approved flow calculation and instrument configuration when preparing an actual loop test.
