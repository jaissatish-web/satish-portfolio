How it works

Pt100: R = 100 × (1 + 3.9083e-3·t − 5.775e-7·t²) [IEC 60751] · TC: E = Etype(Thot) − Etype(Tref) [NIST ITS-90]

Try this example

Look up a Pt100 at 100 °C: 138.5055 Ω (IEC 60751 nominal). A Type K thermocouple with a 0 °C reference produces ≈ 4.096 mV at 100 °C. Use the table mode to print a field crib sheet.

Understand the result

Values are nominal reference data. Tolerance classes (Pt100 Class A/B; TC Class 1/2) are typical and device-dependent — verify with the actual sensor certificate.
