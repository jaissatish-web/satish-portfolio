How it works

Record structure: tag · subsystem · location · issue · category · owner · status · date. Records persist in this browser per project and export to CSV.

Try this example

Add “HV-1002” with issue “Air supply leaks at actuator” under category Piping, owner “mech crew”, status Open. Export the CSV before clearing browser data.

Understand the result

Commissioning-quality records, not an approved ITR substitute. Punch closure requires witness review and project-specific acceptance criteria.
